Pixel Art Editor

A console-based pixel art drawing application built in C, featuring a 15×15 canvas, 16-color palette, and tools to draw, erase, and fill regions — with PNG export and image import.

Features
Draw individual pixels with a chosen color
Erase pixels back to blank
Fill connected color regions (flood fill)
Save canvas as a PNG file
Load an existing image and map it onto the canvas
Mouse-driven interface with keyboard shortcuts
